# Da Paz Confeitaria

Site comercial para bolos de pote e bolos personalizados.

## Recursos identificados
- SEO básico
- Meta description
- Open Graph
- URL canônica
- Estrutura comercial
- Chamada para contato
- Apresentação de produtos

## Objetivo
Criar uma presença digital orientada à divulgação e geração de pedidos para uma confeitaria.
